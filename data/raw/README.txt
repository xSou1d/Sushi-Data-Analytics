# Sushi Restaurant Synthetic Dataset

This dataset is intentionally synthetic and contains controlled data-quality problems.
It is designed for a Python data-analysis project covering data loading, cleaning,
validation, wrangling, aggregation, visualization, time-series analysis, and introductory modeling.

Files:
- menu.csv: menu item information, prices, ingredient costs, and preparation times
- orders.csv: transaction-level order data
- inventory.csv: daily ingredient usage, receiving, waste, and costs
- staffing.csv: daily employee hours and roles

Important:
The raw data intentionally contains missing values, duplicate order records,
inconsistent text values, invalid quantities, and anomalous inventory observations.
Do not clean the raw files manually. The cleaning should be performed programmatically
as part of the project.
